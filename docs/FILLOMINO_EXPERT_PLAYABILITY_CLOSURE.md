## Baseline finding

The multi-size Fillomino generator used an explicit Expert clue target of approximately 52% of cells. On the canonical 6x6 seed `97001`, production generated 19 clues (19/36 = 0.528 density).

Exact baseline audit:

- full solution count: 1
- bare solution count: 2
- removable clues from the 19-clue state: 9
- locally irreducible: false

This proved that the 52% Expert stop was artificial rather than a natural uniqueness frontier.

## Verifier optimization

The legacy exact solver assigns values cell-by-cell and repeatedly recomputes Fillomino components. Sparse puzzles make that search expensive.

A second exact formulation was introduced for the playability path: connected candidate regions are generated by size and the puzzle is solved as a constrained region-partition / exact-cover search. Candidate regions respect given clues and equal-size adjacency restrictions; MRV chooses the next uncovered cell.

Differential evidence on canonical production-derived cases:

- cases: 6
- mismatches: 0
- legacy total: 496.1 ms
- region-exact total: 68.5 ms
- measured speedup: 7.24x

The region-exact solver therefore matched the trusted legacy solution counts on all differential cases before it was used for production hardening.

## Production hardening

The production Expert path keeps the existing seeded multi-candidate Fillomino generation and then applies a deterministic region-exact clue-removal pass.

Production contract:

- no artificial clue floor
- no target clue count used as the final stopping rule
- no runtime cutoff used as an eligibility rule
- every accepted removal preserves exact uniqueness
- deterministic seeded removal order
- local irreducibility follows from monotone non-uniqueness of rejected removals

Metadata:

- verification: `fillomino-region-exact-local-irreducible`
- policy: `contract-driven-local-irreducibility`
- proof: `monotone-nonuniqueness-from-single-pass`
